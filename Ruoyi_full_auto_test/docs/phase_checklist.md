## 仍需你在本机完成的动作

1. 在 Jenkins 页面创建 Pipeline Job，连接 Git 仓库并手动构建一次。
2. 安装 JMeter 后执行性能基线，并把真实数据填入你的测试记录。
3. 将项目提交到自己的 Git 仓库，确保不提交真实密码和 `reports` 运行产物。
4. 根据自己实际操作录制 1~2 分钟演示视频或准备截图。
