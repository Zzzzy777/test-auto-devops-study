# 01_登录鉴权Token自动传递自动化测试.md
## 一、实验目的
1. 掌握Apifox后置脚本提取登录Token并存入环境变量，实现多接口传参
2. 学会Bearer鉴权头配置，完成一次登录、后续接口自动携带令牌
3. 编写状态码、鉴权头、响应结构等常用接口断言
4. 搭建登录、查询列表、新增用户串联自动化场景
5. 能够通过实际请求、控制台排查Token传递异常
6. 运行场景并导出测试报告归档

## 二、实验环境
工具：Apifox
模拟接口：httpbin测试接口
运行环境：自定义测试环境
业务执行链路：登录接口 → 用户列表接口 → 新增用户接口

## 三、完整操作步骤
1. 新建专属测试环境，用于存储token变量
2. 创建自动化场景，按顺序添加登录、用户列表、新增用户三个接口
3. 配置登录接口，在后置脚本中提取返回的token，保存至环境变量，添加状态码基础断言
4. 给用户列表、新增用户接口统一配置Bearer鉴权请求头，引用环境变量中的token
5. 在用户列表接口后置页面编写多条断言，校验接口状态、鉴权头是否正常携带
6. 保存全部接口配置，一键完整运行自动化场景
7. 查看执行结果，核对下游接口实际请求头是否自动携带token，确认全部断言通过
8. 导出HTML测试报告，截图保存运行结果归档

## 四、核心知识点
1. 环境变量：可跨接口存储、读取数据，用来传递登录凭证、业务ID
2. Bearer鉴权：请求头固定格式，通过{{变量名}}动态读取环境变量实现自动填充
3. 接口断言：校验接口返回状态、请求头、返回字段、响应耗时，判断接口是否符合预期
4. 自动化场景：按真实业务顺序编排接口，一键批量执行，用于回归测试

## 五、实验现象与结果
1. 场景依次执行登录、列表查询、新增用户三步接口，无执行顺序错乱
2. 登录成功后，后两个接口的实际请求头自动带上完整Token，无需手动复制
3. 所有测试断言全部绿色通过，无失败用例
4. 导出完整测试报告，可查看每条接口的执行日志与校验结果
