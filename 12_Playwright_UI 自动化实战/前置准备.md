# Playwright UI自动化实战 | 前置准备
>项目：基于 RuoYi‑Vue v3.9.2 做WebUI自动化
>技术栈：Python + pytest + playwright


### 1. Python库环境安装
1. 安装playwright库
```bash
pip install playwright
```

2. 安装浏览器驱动（chromium）
```bash
playwright install chromium
```
>⚠️踩坑提醒：不执行 install，运行脚本直接报浏览器找不到。

### 2. pytest‑playwright
- pytest 的 fixture `page` 由插件自动提供，无需自己写打开、关闭浏览器逻辑。

### 3. 被测服务环境
- 访问地址：`http://localhost:82`
- 测试账号：admin /admin123
- 必须保证**若依后端服务已经启动**，接口正常可访问。
>⚠️后端没启动，所有 UI 脚本全部执行失败。

### Node.js 前端环境说明
- ❗**运行 Playwright 自动化脚本，不需要 Node，不需要启动前端工程。**
- Playwright 只是打开浏览器访问已经可访问的前端地址。
- 只有修改、编译若依前端源码才需要 Node
