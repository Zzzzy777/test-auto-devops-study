# 前置准备：从环境可运行到第一条用例

## 1. 目标

完成本章后，应当能够：

- 创建 Python 虚拟环境并安装依赖
- 安装 Playwright Chromium 浏览器
- 确认 RuoYi 前端和后端服务正常
- 用 headed 模式看到浏览器操作
- 用 headless 模式执行无界面回归
- 区分前端地址、后端 API 地址和 Jenkins 地址

## 2. 环境关系

```text
浏览器 UI 测试 ──> http://localhost:82
                         │
                         └── 前端发起 API 请求 ──> http://localhost:8081

Jenkins ──> http://localhost:8080
```

端口不要混用：

- `82`：Playwright 打开的 RuoYi 前端
- `8081`：Requests/JMeter 调用的 RuoYi 后端
- `8080`：Jenkins，不是 RuoYi API

## 3. 安装 Python 依赖

进入项目目录：

```powershell
Set-Location 'D:\运维测试\test-auto-devops-study\Ruoyi_full_auto_test'
```

创建虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

如果 PowerShell 阻止脚本执行，可以只对当前用户放开本地脚本权限：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

安装依赖：

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 4. 安装浏览器

```powershell
python -m playwright install chromium
```

检查安装是否成功：

```powershell
playwright install --help
```

Playwright 包和浏览器是两件事：`pip install playwright` 只安装 Python 库，仍然需要执行 `playwright install chromium` 下载浏览器。

## 5. 启动并检查被测系统

浏览器访问：

```text
http://localhost:82/login
```

后端接口可以使用 PowerShell 检查端口：

```powershell
Test-NetConnection localhost -Port 82
Test-NetConnection localhost -Port 8081
```

看到 `TcpTestSucceeded : True` 才说明端口可连接。端口可连接不等于业务一定正常，还需要实际登录或调用接口验证。

## 6. 第一次运行

先运行登录用例：

```powershell
pytest test_ui/test_ruoyi_login.py -s --headed --slowmo=600
```

参数含义：

| 参数 | 作用 |
|---|---|
| `-s` | 输出日志和 print 内容 |
| `--headed` | 显示浏览器窗口 |
| `--slowmo=600` | 每个 Playwright 操作额外放慢 600ms，便于观察 |
| 不传 `--headed` | 使用 headless 模式 |

再运行新增用户：

```powershell
pytest test_ui/test_ruoyi_user_add.py -s --headed --slowmo=600
```

最后执行全量：

```powershell
pytest test_ui test_api -s --browser chromium
```

## 7. 环境变量

默认配置在 `../Ruoyi_full_auto_test/common/config.py`，更推荐使用环境变量覆盖：

```powershell
$env:RUOYI_FRONTEND_BASE_URL = 'http://localhost:82'
$env:RUOYI_API_BASE_URL = 'http://localhost:8081'
$env:RUOYI_UI_USERNAME = 'admin'
$env:RUOYI_UI_PASSWORD = 'admin123'
$env:RUOYI_API_USERNAME = 'admin'
$env:RUOYI_API_PASSWORD = 'admin123'
```

不要把真实密码写进测试代码或提交到 Git。

## 9. 常见前置问题

### `pytest` 不是内部或外部命令

确认虚拟环境已经激活，或者使用：

```powershell
python -m pytest test_ui/test_ruoyi_login.py
```

### 浏览器启动失败

重新安装浏览器：

```powershell
python -m playwright install chromium
```

### 登录页打不开

先检查 82 端口和 RuoYi 前端服务，再确认 `RUOYI_FRONTEND_BASE_URL` 没有写成 8081。

### API 登录失败

确认后端地址是 8081、账号密码有效，并检查后端是否要求验证码或其他登录字段。
