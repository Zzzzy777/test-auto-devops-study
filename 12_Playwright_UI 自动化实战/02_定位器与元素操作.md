# 02 定位器与元素操作

## 1. 定位器选择优先级

推荐优先级：

1. `get_by_role()`：按用户看到的角色定位
2. `get_by_label()`：按表单标签定位
3. `get_by_placeholder()`：按输入框提示定位
4. `get_by_text()`：按可见文本定位
5. `get_by_test_id()`：项目有稳定测试属性时优先
6. CSS：页面没有更好语义时使用
7. XPath：复杂、兼容旧页面时最后考虑

示例：

```python
page.get_by_role("button", name="新增").click()
page.get_by_label("用户昵称").fill("测试用户")
page.get_by_placeholder("请输入用户名").fill("ui_test_demo")
page.get_by_text("用户管理", exact=True).click()
page.get_by_test_id("submit-user").click()
```

定位器的目标是表达业务意图，而不是依赖脆弱的 DOM 层级。

## 2. 为什么会出现 strict mode violation

Playwright 默认要求一个操作定位器最终只匹配一个元素。如果定位器匹配两个按钮，就会报 strict mode violation：

```python
# 可能同时匹配搜索按钮和弹窗提交按钮
page.get_by_text("确定").click()
```

改进方法：

```python
# 先限定弹窗，再找弹窗内的按钮
submit = user_page.add_dialog.get_by_role("button", name="确定")
submit.click()
```

也可以使用 `first`/`last`，但只能在你明确知道元素顺序稳定时使用：

```python
page.locator("button.el-button--primary").first.click()
```

`first` 不是万能修复，它可能掩盖定位器写得不准确的问题。

## 3. exact 与文本包含匹配

```python
# 包含匹配，可能命中多个元素
page.get_by_text("用户").click()

# 精确匹配，适合菜单名称
page.get_by_text("用户管理", exact=True).click()
```

当页面有“用户管理”“用户新增”“用户详情”等多个文本时，优先使用 `exact=True` 或缩小父容器范围。

## 4. 表格行定位

用户列表的典型需求不是“点击第 2 行”，而是“找到用户名等于目标值的行”：

```python
row = page.locator(".el-table__row").filter(
    has_text="ui_test_demo"
).first

expect(row).to_be_visible()
```

更稳妥的封装：

```python
from playwright.sync_api import Locator


def user_row(page, username: str) -> Locator:
    return page.locator(".el-table__row").filter(has_text=username).first
```

如果用户名可能是其他字段的子串，应进一步定位单元格：

```python
row = page.locator(".el-table__row").filter(
    has=page.locator(".cell", has_text=username)
).first
```

## 5. 弹窗定位

页面上可能同时存在隐藏弹窗和当前显示弹窗。要增加 `:visible` 和标题限制：

```python
add_dialog = page.locator(".el-dialog:visible").filter(
    has_text="添加用户"
).first

expect(add_dialog).to_be_visible()
add_dialog.get_by_role("button", name="确定").click()
```

不要只写：

```python
page.locator(".el-dialog").get_by_text("确定").click()
```

因为隐藏 DOM 也可能被匹配，或者多个弹窗同时存在。

## 6. 表单输入方式

```python
# 文本框
locator.fill("value")

# 下拉框
locator.click()
page.get_by_text("男", exact=True).click()

# 复选框
locator.check()

# 单选框
locator.check()

# 文件上传
locator.set_input_files("data/test.txt")
```

`fill()` 会清空原有值后输入，适合编辑场景；`press_sequentially()` 更接近真实键盘输入，适合需要触发逐字输入事件的场景。

## 7. 过滤器组合

Locator 可以继续缩小范围：

```python
form = page.locator(".el-form:visible").filter(has_text="添加用户")
username = form.locator("input").nth(0)
```

常见过滤方式：

```python
locator.filter(has_text="目标文本")
locator.filter(has=page.locator(".child"))
locator.locator(".child")
locator.nth(0)
```


```powershell
pytest test_ui/test_ruoyi_user_add.py -s --headed --slowmo=600
```

```python
page.pause()
```

暂停后使用 Playwright Inspector 检查定位器，确认匹配数量和元素状态。
