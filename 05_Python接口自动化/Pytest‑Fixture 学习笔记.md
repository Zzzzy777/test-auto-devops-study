# Pytest Fixture 夹具学习笔记

## 1、什么是Fixture
Fixture是pytest提供的夹具功能，用来做**前置准备、后置清理**。
- 前置：登录、造测试数据、打开连接
- 后置：退出登录、删除测试数据、关闭连接
- 可以把准备好的数据/对象，传给测试用例使用，**避免重复写代码**

> 对比：
> 传统：每个用例自己写一遍登录代码，代码大量重复
> fixture：只写1次登录，多个用例直接拿来使用

## 2、基础语法格式
```python
import pytest

@pytest.fixture()
def 夹具函数名():
    # --------前置代码（用例执行之前运行）--------
    print("执行前置操作")
    
    yield 要传给用例的数据
    
    # --------后置代码（全部用例跑完之后运行）--------
    print("执行后置清理")
```

>✨重点：yield是分界线
>yield上面：前置，用例运行之前执行
>yield：把数据交给测试用例
>yield下面：后置，用例执行完成之后执行

### 使用夹具：把夹具名字写进用例参数
```python
def test_demo(夹具函数名):
    # 直接拿到yield返回的数据
    pass
```

## 3、 scope 作用域
### scope 控制夹具代码多久执行一次
| scope 取值	执行时机 | 2 条用例执行次数 | 适用场景 |
| --- | --- | --- |
| function（默认） | 每条用例前后都会执行一次夹具 | 执行 2 次 | 每条用例需要全新数据 |
| module | 整个 py 文件只执行 1 次夹具 | 只执行 1 次	登录获取 token，文件内全部用例共用登录 |

### 写法
```python
@pytest.fixture(scope="module")
def get_token():
    pass
```

#### 现象区分（控制台打印看证据）
1. scope="module"
- 登录打印日志只出现 1 次，后面其他用例直接复用 token，不会重复登录。
- 后置代码，等这个 py 文件全部用例跑完才执行。
2. scope="function"
- 每跑一条用例，都会打印一次登录、一次后置清理。

## 3、实操要点 & 踩坑记录
1. pytest 的测试文件、用例函数名必须以test_开头，否则识别不到
2. yield 是关键，不要写成 return，return 之后后面代码永远不会运行
3. scope="module"：整个 py 文件只登录一次，适合 token 复用场景
