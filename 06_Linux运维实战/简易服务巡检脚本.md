# 8.25 简易服务巡检脚本
## 学习目标
1. 编写 shell 脚本批量检测Linux多个服务存活状态
2. 通过 `systemctl is‑active` + 返回值 `$?` 判断服务状态
3. 正常绿色输出、异常红色输出，打印提示
4. 模拟服务故障，验证脚本检测效果

## systemctl核心命令表格
| 命令 | 说明 |
| ---- | ---- |
| `systemctl status 服务名` | 查看服务状态，看是否正在运行 |
| `systemctl start 服务名` | 启动服务 |
| `systemctl stop 服务名` | 停止服务 |
| `systemctl restart 服务名` | 重启服务（先停止再启动） |
| `systemctl enable 服务名` | 设置开机自动启动 |
| `systemctl disable 服务名` | 取消开机自动启动 |
| `systemctl is‑active 服务名` | 仅判断服务运行状态，输出 active/inactive |

## 原理说明
- `systemctl is-active 服务名`：只输出服务状态，不打印大量详情，适合脚本调用
- `$?`：上一条命令执行后的返回码
  - 返回 `0` → 服务运行正常
  - 返回非0 → 服务异常/未运行
- `&>/dev/null`：把命令输出全部屏蔽，不在屏幕打印
- `echo -e "\033[32m文字\033[0m"`：Linux终端颜色输出

## 完整脚本 service_check.sh
```bash
#!/bin/bash

# 填写本机真实存在的服务名称
service_list="sshd cron systemd-journald"

echo "====== 服务巡检开始 ======"
echo "检测时间：$(date "+%Y-%m-%d %H:%M:%S")"
echo "-------------------------"

for service in $service_list
do
    systemctl is-active $service &>/dev/null
    if [ $? -eq 0 ];then
        echo -e "\033[32m$service 运行正常\033[0m"
    else
        echo -e "\033[31m$service 异常未运行\033[0m"
    fi
done

echo "-------------------------"
echo "====== 巡检结束 ======"
```

## 最基础简易脚本（必须掌握）
```bash
#!/bin/bash
systemctl is-active sshd &>/dev/null
if [ $? -eq 0 ];then
    echo "sshd服务正常"
else
    echo "sshd服务异常！"
fi
```
