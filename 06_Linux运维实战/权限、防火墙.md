# 权限、防火墙
> 学习目标：修改文件权限；防火墙放行端口，实现外部访问虚拟机服务
> 环境：Ubuntu22.04

## 1. 文件权限管理
### chmod 修改读写执行权限
`chmod`：修改文件/文件夹读写、执行权限
```bash
touch test_demo.sh           # 创建测试文件
chmod +x test_demo.sh        # 添加可执行权限（shell脚本常用）
chmod 755 test_demo.sh       # 设置755权限，脚本、服务最常用
chmod 777 test_demo.sh       # 设置777全部权限，仅本地测试，生产禁止使用

mkdir test_dir
chmod -R 755 test_dir        # -R 递归：修改文件夹以及内部所有文件权限
ls -l                        # 查看文件权限
```

### 权限数字说明
| 权限数字 | 权限符号 | 说明 | 适用场景 |
| --- | --- | --- | --- |
| 755 | `-rwxr‑xr‑x` | 属主读写执行；其他用户读、执行 | 脚本、项目文件夹 |
| 777 | `-rwxrwxrwx` | 所有用户读写执行 | 仅测试使用，生产严禁 |

- ls -l 输出权限解读：
- 第 1 位：-普通文件，d代表文件夹
- 2‑4 位：文件拥有者（属主）权限
- 5‑7 位：同组用户权限
- 8‑10 位：其他用户权限

### chown 修改文件归属用户
#### chown：修改文件属于哪个用户、用户组
```bash
sudo chown ubuntu:ubuntu test_demo.sh          # 修改文件归属 用户:用户组
sudo chown -R ubuntu:ubuntu test_dir           # -R递归修改文件夹全部内容归属
ls -l
```

| 命令  | 作用 |
| --- | --- |
| chmod | 修改读写、执行权限 |
| chown | 修改文件所属用户与用户组 |
| -R | 递归，只针对文件夹生效 |


## 2. ufw 防火墙端口放行
> ⚠重要警告：开启防火墙 / 重置防火墙之前，务必先放行 22 端口，否则 Xshell SSH 直接断开，无法连接虚拟机！
```bash
sudo ufw status                  # 查看防火墙状态
sudo ufw enable                  # 开启防火墙
sudo ufw disable                 # 关闭防火墙

sudo ufw allow 22                # 放行SSH远程22端口
sudo ufw allow 3306              # 放行MySQL数据库3306端口
sudo ufw allow 8080             # 放行业务8080端口，外部机器可以访问服务

sudo ufw delete allow 8080       # 取消8080端口放行
sudo ufw status verbose          # 查看防火墙完整详细规则

# 只允许指定IP访问端口（生产安全配置）
sudo ufw allow from 192.168.86.1 to any port 3306

sudo ufw deny 9000               # 拒绝外部访问9000端口

# 重置全部防火墙规则（重置前必须allow 22！！）
sudo ufw allow 22
sudo ufw reset
```

### 防火墙状态说明
1. Status: active：防火墙已经开启，端口不放行外部访问不通
2. Status: inactive：防火墙关闭，所有端口全部可以访问
