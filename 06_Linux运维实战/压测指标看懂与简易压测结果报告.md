# 压测指标看懂
## 实训目标
看懂三大核心压测指标：**响应时间、吞吐量、错误率**；仅做基础解读，不做深度性能调优，输出简易压测结果报告。

## 一、三大核心指标（必须掌握）
### 1. 响应时间
含义：从发送请求到接收完整返回数据的耗时，单位 ms（毫秒），数值越小接口越快。
JMeter聚合报告中，平均值、中位数、90%百分位、95%百分位、99%百分位，全部属于响应时间相关指标。
> 重点参考：**90%百分位（P90）**，代表90%用户的请求耗时，更贴合真实用户体验。

### 2. 吞吐量
含义：单位时间内系统能够处理的请求数量，代表服务处理能力。
JMeter单位常见：请求/分钟、请求/秒（QPS/TPS）。
> 低压场景下吞吐量数值偏低属于正常现象，不代表服务上限。

### 3. 错误率（异常%）
含义：压测失败请求占全部请求的百分比。
合格标准：业务正常压测，错误率要求 **0.00%**。
失败常见原因：网络不通、服务停止、参数错误、并发过高服务超时拒绝连接。

## 二、聚合报告字段说明
| 字段 | 含义 |
| ---- | ---- |
| #样本 | 本次压测发起总请求次数 |
| 平均值 | 所有请求平均响应时间（ms） |
| 中位数 | 一半请求耗时低于该数值（ms） |
| 90%百分位 | 90%请求耗时不超过该数值（ms，核心指标） |
| 最小值 / 最大值 | 单次请求最快、最慢耗时（ms） |
| 异常 % | 请求错误占比（错误率） |
| 吞吐量 | 单位时间处理请求数量 |

## 三、简易压测结果报告（本次实操数据）
### 1. 压测基础信息
- 压测工具：Apache JMeter 5.6.3
- 被测接口：http://192.168.86.100:8080/
- 线程组配置：10并发线程，Ramp-Up=3秒，循环2次
- 总请求样本：22

### 2. 核心指标汇总
| 核心指标 | 测试结果 |
| ---- | ---- |
| 平均响应时间 | 23 ms |
| 90%响应时间 | 9 ms |
| 错误率 | 0.00% |
| 吞吐量 | 9.0 请求/分钟 |

### 3. 压测结论
1. 本次低压并发压测，错误率0%，Tomcat服务运行稳定，无请求失败；
2. 接口平均响应23ms，90%请求仅9ms，接口响应速度优秀；
3. 当前并发压力较小，未达到服务性能上限，本次仅完成接口基础可用性验证。

## 四、学习重点总结（面试背诵）
1. JMeter聚合报告没有单独一列叫响应时间，平均值、百分位均用来衡量响应耗时；
2. 评估性能优先看90%百分位，平均值容易被极端慢请求干扰，不能代表大多数用户；
3. 初级测试岗位只需要看懂指标、输出简易报告，不用深入性能调优。
