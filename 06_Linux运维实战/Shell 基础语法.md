# Shell 基础语法
> 学习目标：掌握变量、if 判断、for 循环；能看懂并编写短小实用脚本
> 实战产出：简单端口检测脚本

## 1. Shell 脚本入门
Shell 脚本：将多条 Linux 命令按顺序写入 `.sh` 文件，批量自动执行。

### 第一个脚本运行三步法
```bash
# 1. 创建文件
touch first.sh

# 2. 编辑内容（首行固定声明解释器）
#!/bin/bash
echo "hello shell"

# 3. 添加执行权限并运行
chmod +x first.sh
./first.sh
```

>首行 #!/bin/bash 为固定写法，指定 bash 解释器。

## 2. 变量
### 定义与使用
1. 定义：变量名=值，等号两边不能有空格
2. 使用：$变量名
```bash
#!/bin/bash
name="ubuntu"
port=8080

echo "用户名：$name"
echo "端口号：$port"
```

### 高频系统内置变量
| 变量  | 含义                     | 说明                                   |
| ----- | ------------------------ | -------------------------------------- |
| `$PWD` | 当前所在目录路径         | 获取当前工作目录                       |
| `$USER`| 当前登录用户名           | 判断执行脚本的用户                     |
| `$?`   | 上一条命令执行返回值     | `0` 代表成功，非 0 代表失败            |
| `$1 $2`| 脚本第 1、2 个入参       | 脚本外部传参使用                       |

> `$?` 是条件判断核心，常用于判断命令、端口检测是否成功。

## 3. if 条件判断
### 基础语法
```bash
if [ 条件 ]; then
    满足条件执行
else
    不满足条件执行
fi
```

>⚠️ 注意：[ 后、] 前必须有空格。

### 常用判断条件
| 条件写法             | 含义                 |
| -------------------- | -------------------- |
| `[ $a -eq $b ]`      | 数字相等             |
| `[ $a -ne $b ]`      | 数字不相等           |
| `[ -f 文件路径 ]`    | 判断文件是否存在     |
| `[ -d 目录路径 ]`    | 判断目录是否存在     |

### 判断命令是否执行成功
```bash
if 命令; then
    echo "执行成功"
else
    echo "执行失败"
fi
```

## 4. for 循环
### 批量重复执行命令，适合多端口、多文件批量操作。
```bash
for 变量 in 值1 值2 值3
do
    循环执行的命令
done
```

### 示例：批量打印端口
```bash
#!/bin/bash
for port in 22 80 3306 8080
do
    echo "检测端口：$port"
done
```
