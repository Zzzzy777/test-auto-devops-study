## 2. 测试目标

本项目主要验证 mall 电商系统的核心业务功能、接口功能、页面交互以及关键业务链路是否正常。

主要目标如下：

1. 验证后台管理系统可以正常登录和退出；
2. 验证商品、分类、品牌等后台管理功能；
3. 验证商城首页、商品列表和商品详情功能；
4. 验证用户登录、购物车和订单流程；
5. 发现并记录系统缺陷；
6. 为后续接口自动化、UI 自动化和性能测试提供测试基础；
7. 将测试执行接入 Jenkins，生成 Allure 测试报告。

## 6. 测试策略

### 6.1 手工功能测试

首先通过浏览器手工验证核心业务流程，确认系统基本功能和业务规则。

### 6.2 接口自动化测试

针对登录、商品、用户、购物车和订单等核心接口编写自动化测试。

### 6.3 UI 自动化测试

使用浏览器自动化工具验证后台和商城的关键页面流程。

### 6.4 性能测试

使用 JMeter 对以下接口进行基础性能测试：

- 后台登录接口；
- 商城首页接口；
- 商品列表接口；
- 商品详情接口；
- 用户登录接口。

### 6.5 持续集成测试

通过 Jenkins 自动执行：

- 接口测试；
- UI 测试；
- JMeter 性能测试；
- Allure 报告生成；
- 测试结果归档。

## 9. 缺陷等级

### 严重缺陷

系统无法使用或核心流程完全中断。

例如：

- 后台无法登录；
- 商品无法展示；
- 无法提交订单；
- 服务启动失败。

### 高级缺陷

重要功能异常，但系统其他部分仍可使用。

例如：

- 商品无法新增；
- 购物车金额计算错误；
- 订单状态更新失败。

### 中级缺陷

普通功能异常，对主要流程影响较小。

例如：

- 查询条件失效；
- 分页显示异常；
- 部分字段校验缺失。

### 低级缺陷

页面展示、文字、样式等问题。

例如：

- 文案错误；
- 页面间距异常；
- 图片尺寸不一致。
